# Verdélia

Propuesta HTML navegable para aprobar la interfaz de ventas, inventario, combos y control financiero interno.

## Abrir la muestra

Abrir `verdelia-propuesta.html` o servir esta carpeta con un servidor web estático. No requiere instalación ni compilación.

## Alcance actual

- Dashboard, inventario filtrable, formularios de producto y combo, pedidos, caja y Link de venta.
- Venta simulada con actualización de existencias y cifras de ejemplo.
- Carrito compartiendo ingredientes y vista previa del mensaje de WhatsApp.
- Favicon, logo SVG, iconos de app 192/512, icono Apple 180 y manifest web.
- Diseño adaptable a PC y celular, controles compactos y formularios laterales.

**Es un prototipo para revisión.** Los datos son ficticios, viven en memoria y se reinician al recargar. No hay autenticación, Supabase, operaciones contables reales ni envío de WhatsApp. El manifest y los iconos preparan la identidad web/app; instalación definitiva, alojamiento HTTPS y política de conexión se resolverán en la implementación aprobada.

El repositorio almacena el código. La aplicación aún no está publicada como servicio en internet.

## Decisiones pendientes

Aprobación visual, WhatsApp de destino, recogida/domicilios y equivalencia de libra utilizada por el negocio. Después: Supabase, permisos privados, movimientos consistentes, precios históricos, reservas y publicación.

Ver `docs/design-direction.md` para la referencia y las decisiones visuales.
